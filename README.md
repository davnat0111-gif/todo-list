# Список задач

Веб-приложение To-Do List в духе бумажного ежедневника. Написано на чистых HTML, CSS и JavaScript, без фреймворков и сборки.

**Рабочий сайт:** https://davnat0111-gif.github.io/todo-list/

## Возможности

- Добавление, отметка и удаление задач
- Сохранение задач после обновления страницы (`localStorage`)
- Отмена удаления
- Фильтры «Все», «Активные», «Готовые» и очистка выполненных
- Кольцо прогресса и сегодняшняя дата
- Светлая и тёмная тема
- Адаптивная вёрстка, управление с клавиатуры и учёт настройки «уменьшить движение»

## Запуск

Откройте `index.html` в браузере.
